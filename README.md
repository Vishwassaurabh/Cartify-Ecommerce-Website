## 📌 Overview

Cartify is a modern Full Stack Ecommerce Website built using the MERN Stack.
It provides users with a smooth online shopping experience with authentication, cart management, admin dashboard, and payment integration.

---

# ✨ Features

✅ User Authentication & Authorization
✅ Add to Cart Functionality
✅ Product Management
✅ Admin Dashboard
✅ Secure Payment Integration
✅ Responsive UI Design
✅ REST API Integration
✅ Modern Ecommerce Interface

# ⚡ Installation & Setup

## Clone Repository

```bash
git clone https://github.com/Vishwassaurabh/cartify.git
```

## Frontend Setup

```bash
cd frontend
npm install
npm start
```

## Backend Setup

```bash
cd backend
npm install
npm run server
```

---

# 🌐 Environment Variables

Create a `.env` file inside backend folder and add:

```env
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
PORT=5000
```
